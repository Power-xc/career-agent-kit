# 서류 보관함

| 폴더 | 무엇 |
| --- | --- |
| `최신/` | 지금 내는 기본본. 파일 이름에 날짜를 붙이지 않고 같은 이름으로 교체한다 |
| `회사별/<YYYY-MM-DD>_<회사>_<직무>/` | 실제로 낸 서류 그대로. 낸 뒤에는 고치지 않는다 |
| `보관/<YYYY-MM-DD>_<설명>/` | 교체된 이전 최신본. 지우지 않는다 |

PDF는 `out/`에서 만들고 여기 파일을 직접 고치지 않는다. 지원 기록(`records/applications.yaml`)의 `documents`가 `회사별/` 폴더를 가리킨다. PDF는 git에 넣지 않는다.
